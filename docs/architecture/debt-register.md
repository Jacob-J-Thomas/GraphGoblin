# Debt register

Companion to the [architecture snapshot](README.md); written for issue #163 against commit `c379f80`. Evidence classes: **Observed** = reproduced with a command or test run for this report (the command is named); **Risk** = read from the code; **Hypothesis** = unverified. Scratch reproductions ran in a disposable copy of the commit; nothing in the repository was changed. No runtime behaviour is claimed verified beyond the Observed rows. A bare `:N` in a row refers to line N of that row's location file.

## Recommendations

Ordered so that each step leaves a clean starting point for the next. "New" proposals were checked against the open-issue list in the #163 brief; none duplicates an open issue.

1. **#152 (reuse) - Fresh SQLite initialization commits its marker with the schema.** Scope: one write transaction for fresh migrations and marker. Acceptance: as in #152. Dependencies: none. Decision: plan approval only. Why first: format 4 rewrites the same stamp code.
2. **#118 (reuse) - Preserve terminal run provenance when deleting loops.** Scope: hidden, disarmed versions for deleted loops plus orphan detection and repair. Acceptance: as in #118, plus the scratch reproduction in D5 passes the inventory. Dependencies: none. Decision: deleted-loop retention policy (hide and disarm recommended).
3. **#127 (reuse) - Invalidate cached consumer results.** Scope and acceptance as in #127. Dependencies: none. Decision: none. Cheap, and protects the cutover branch from stale local greens.
4. **New - "Runs: generic cursor paging without the template store".** Scope: move `runPage` cursor paging into `SqliteRunRepository`; `GET /runs` returns `RunRecord`; drop repository/issue/PR/head/merge/instance filters; regenerate client and reference. Acceptance: paging order, cursor validation and owner scoping tests pass with the template store removed from the route; web runs list unchanged. Dependencies: none; precedes #165. Decision: drop the GitHub subject filters (follows #165 (a)).
5. **New - "Storage: one format constant and declarative startup readiness".** Scope: D6, D9, D12, D25: single format constant, readiness checks keyed by format, a single guard run per start, per-run streaming in inspect and apply, Drizzle snapshot parity plus a CI no-op check. Acceptance: existing upgrade tests and `pnpm test:upgrade` pass; a large synthetic store upgrades in bounded memory; `drizzle-kit generate` emits nothing. Dependencies: 1. Decision: retention of `gg_upgrade_archive` rows.
6. **#165 (reuse) - Templates are starting points only.** Scope as settled: option (a), delete `examples/aidlc`. Order inside: item 4 first, then the six seams of D1, then storage (D3) in the format-4 migration. Dependencies: 4, 5. Decision: settled; disposition of existing bound instances and runs at cutover.
7. **#167 then #164 (reuse) - Exit loop-back decision, then decisions and exits format 4.** Scope as settled; include D23. Dependencies: #167 before the exit portion; 5. Decision: #167 keep or replace loop-back.
8. **#168 (reuse) - Trigger configuration redesign.** Scope as settled, explicitly including D7 (one atomic admission path), D17 (2xx once saved), D18, D19 and D29. Dependencies: 5. Decision: whether identical authenticated bodies may be consumed again.
9. **New - "Format 4: one offline cutover for #164, #165 and #168".** Scope: the shared v3-to-v4 stage, manifest schema, history pass (including D22), template subject archive, migration 0012 and the docs refresh of D26. Acceptance: inventory refuses nonterminal runs and pending receipts; replay parity on converted histories; backup, hash, rehearsal and restore documented; fresh and upgraded stores pass the same guard. Dependencies: 1, 2, 5, 6, 7, 8. Decision: the owner may instead fold this into #164's plan.
10. **New - "Retention: bounded purge of terminal history".** Scope: D11. Acceptance: purge by age or count for terminal runs, events, artifacts and inbound events; receipts keep hashes; active runs and pins untouched; documented in docs/11. Dependencies: 9. Decision: the retention policy itself (docs/11 currently says keep everything).
11. **New - "Web: load offline conversion lazily and split the bundle".** Scope: D10. Acceptance: initial chunk excludes the frozen schemas; device-draft conversion still works offline after first load. Dependencies: 9 (stages change). Decision: none.
12. **#117 (reuse) - Bound HTTP probe reads.** Independent; any time. Decision: byte limit (1 MiB proposed in the issue).
13. **#114 (reuse) - esbuild advisory via drizzle-kit.** After 5 so snapshot parity is already checked. Decision: none.
14. **#39 (reuse, backlog) - Codex as an installed prerequisite.** Unchanged scope; remains parked until the owner unparks it. Decision: unpark timing.
15. **New - "Engine: split RunManager by responsibility".** Scope: D20, with D21 measured first. Acceptance: no behaviour change; engine coverage and recovery tests unchanged. Dependencies: 9. Decision: whether to schedule before or after #166 findings.
