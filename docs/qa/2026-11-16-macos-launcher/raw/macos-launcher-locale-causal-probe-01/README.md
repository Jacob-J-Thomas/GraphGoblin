# Launcher locale causal probe preparation

The matched owner IPS reaches Foundation's sorted JSON path in `admissionDocument`. This standalone probe exercises the same admission dictionary using the retained app's exact diagnostics root and its current inode/device metadata. It compiles a small Swift executable through the pinned owner Command Line Tools with the macOS 15 arm64 target. It does not execute GraphGoblin, Node as part of a case, an installer, a shell gateway, a browser or a network request. Node is used as the existing readback transport.

Each case starts a fresh process with the same explicit HOME, PATH and private TMPDIR. The only test environment differences are the locale values recorded in the failed launch. A uses sorted JSONSerialization with valid locale values. B uses the exact two invalid values. C uses the same invalid values with unsorted JSONSerialization. D uses typed JSONEncoder with sorted keys. E isolates invalid LC_ALL. F isolates invalid LANG. The successful document must match the same four fields and values. The receipt records per-case PID, actual exit, signal, stdout/stderr and both pipe EOFs. A captured crash is a result, not a transport failure.

The source, module cache and executable are staged once in a fresh private cache directory. The 60-second compile and five-second cases have bounded EOF readback. A reached timeout can signal only the direct process owned by the probe. It never signals app or gateway processes, deletes files, or alters the app, store, logs or preferences. The command disables core dumps for its own descendants. macOS may still create a system crash report for an intentionally reproduced fault. There is no cleanup or retry. The SSH wrapper has a 120-second outer bound.

After root review, use `node <absolute path>/run-locale-probe.mjs --preview` to obtain the exact remote command hash, then a single `--run <commandSha256>`. The packet has not executed.
