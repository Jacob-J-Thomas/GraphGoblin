This publication is a bounded evidence snapshot for PR 501. It separates historical evidence from the latest local candidate and records the remaining gates. It is not a delivery-complete claim.

## Candidate and delivery state

The latest product source is `18089bba4b1c5f4fad19627d4c118b48b656a247`, tree `c6781a4daf2c2b2ee57cd031a774d9724a038787`. It removes the installer configuration's unnecessary sorting and adds a malformed-locale public-install regression. Owner build #05 and engineering acceptance #04 passed. All five CI #03 jobs passed at published checkpoint `635a637c4be4f8d63647c01996cdb80e3c262323`, whose product paths equal `18089bba`. The native coverage implementation is published, but its hosted build has not reached test execution. Required Finder/Dock observations and final audit remain pending. The owner approved 90% Swift lines and regions plus explicit branch-outcome tests and clarified shutdown to use the existing authenticated API on November 16. Earlier failed attempts retain their original outcomes.
