## What the retained observations establish

Vitest 5.0.3's public `beforeEach` hook waits at a rendezvous. The programmatic public cancellation command `cancelCurrentRun('keyboard-input')` delivers a real enclosing `TestRunAbortError`; the hook then returns normally. The maintained callback enters with its signal already aborted. Windows native child execution is observed without replacing that execution. Runtime: Node 22.23.4, pnpm 12.8.1, `LIVE=0`.
