# Independent Windows QA for issue #466

Independent behavior QA found a diagnostic gap. The candidate settled the probe, native fake CLI and delayed filesystem operation before the successor test in the tested cases. When both the timed-out body and case-root removal failed, Vitest retained the timeout and root failure and dropped the late body failure.
