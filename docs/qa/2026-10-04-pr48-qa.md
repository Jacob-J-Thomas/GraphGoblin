## Defects

### PR48-QA-01 — Major: Adding a script argument restores earlier argument text and autosaves the loss

- **Steps:** Seed a script with args=["--version"]. Open its editor. Replace Args 1 with {{ vars.value }} and wait for All changes saved. Without closing the editor, click Add args and enter second in Args 2.
- **Expected:** Args 1 stays {{ vars.value }}; autosave stores ["{{ vars.value }}","second"].
- **Actual:** Args 1 changes back to --version. The API draft now holds ["--version","second"]. The lost text had already reached the server before Add args. Closing/reloading between editing and adding avoids the reproduction because it changes the form’s initial value.
- **Evidence:** dark: [PNG](2026-10-04-pr48-qa/271-dark-editing-script-argument-then-adding-retains-newest-text.png); light: [PNG](2026-10-04-pr48-qa/287-light-editing-script-argument-then-adding-retains-newest-text.png). Runtime/API observations are recorded in the catalogue and verification.json.
- **Attribution:** The array field implementation is unchanged relative to local main. This is a current full-regression defect, not established as introduced by #48.

### PR48-QA-02 — Minor: Double-click on a node outside the eventual dialog bounds dismisses its editor immediately

- **Steps:** Open a nine-node editor at 1440×900. Double-click a node header near the canvas’s left or right edge (for example wait, or start in a fresh grid).
- **Expected:** The repeated activation leaves one editor open and editable.
- **Actual:** The first click opens the dialog. The second click lands on its backdrop and closes it. After the double-click there are zero dialogs. A single click works.
- **Evidence:** dark: [PNG](2026-10-04-pr48-qa/016-dark-double-click-opens-one-editor.png); light: [PNG](2026-10-04-pr48-qa/054-light-double-click-opens-one-editor.png). Runtime/API observations are recorded in the catalogue and verification.json.
- **Attribution:** Reproduced in both themes. The specification defines single-click and drag behavior; this finding records a usability failure of repeated pointer activation.

### PR48-QA-03 — Minor: Loop-variable JSON editor collapses to a sliver and cannot receive an ordinary pointer click

- **Steps:** Expand Loop. In Variables, click Add entry and rename the key to qaValue. Scroll the panel to its bottom and click the JSON value editor.
- **Expected:** A readable JSON value editor remains inside the row and accepts pointer focus.
- **Actual:** The editor is compressed beside the full-width key input. CodeMirror content measures 31.5 px wide; its centre hits the sibling row instead of the editor, and an ordinary click times out. The visible wrapper is a thin strip. The newly added value remains null and validation blocks saving until a value is entered. Tab/focus plus keyboard entry works; the resulting variable schema saves and reloads.
- **Evidence:** dark: [PNG](2026-10-04-pr48-qa/296-dark-variable-json-record-editor-is-reachable-by-pointer.png); light: [PNG](2026-10-04-pr48-qa/300-light-variable-json-record-editor-is-reachable-by-pointer.png). Runtime/API observations are recorded in the catalogue and verification.json.
- **Attribution:** Record-field implementation is unchanged relative to local main. No attribution to the modal/panel change is claimed.

### PR48-QA-04 — Cosmetic: Empty optional heartbeat Until shows a compile-error preview (known D30)

- **Steps:** Open a heartbeat whose Max beats is 3 and whose optional Until field is empty.
- **Expected:** The optional empty expression has no failure preview.
- **Actual:** The preview says expression failed to compile: Unexpected end of expression. The heartbeat configuration is valid because Max beats is present.
- **Evidence:** dark: [PNG](2026-10-04-pr48-qa/279-dark-blank-optional-heartbeat-expression-has-no-error-preview.png); light: [PNG](2026-10-04-pr48-qa/295-light-blank-optional-heartbeat-expression-has-no-error-preview.png). Runtime/API observations are recorded in the catalogue and verification.json.
- **Attribution:** Known D30 from docs/qa/2026-10-03-wp-d2.md; not a newly attributed regression.
