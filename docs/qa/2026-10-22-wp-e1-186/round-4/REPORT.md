## 7. Decisions and parameters

Terminal rows precede terminal status writes but are not necessarily the last stored rows: return-delivery bookkeeping follows, and started/resumed supersede earlier outcomes (the existing engine terminalEvent rule). The single writer now delivers all replay/held rows before checking the current lifecycle. It then reads another bounded page AFTER the lookup; more rows, overflow or held notifications return to catch-up. Once the terminal outcome is consumed and the confirmed tail is empty, completion is written through the existing backpressure machinery before closing. This acknowledges the confirmation snapshot; subsequent resume/audit appends require another subscription from the cursor.

Controls have no id. The completion payload confirms the existing cursor (including a past-end cursor) rather than inventing a new durable seq. The client validates it against lastSeq and resolves; malformed controls are fatal RunEventParseError. It delivers terminal rows like any other historical event, and EOF without completion remains retryable even after such a row. A single retryableProblem policy makes STORED_EVENT_INVALID fatal for both HTTP and stream controls while preserving transient 5xx retries. The hook always confirms cached histories through this protocol.

Empty terminal cursors use three empty bounded page reads and two fixed lifecycle lookups rather than round 3's two reads/one lookup; the added tail read closes the lookup/append race while work remains independent of history length. Each lifecycle lookup remains five seeks on the existing index and at most one decoded marker. The 128-event page, 256-event/1 MiB handoff queue, 16 KiB write chunks, 256 KiB writable ceiling, 5-second drain timeout and 2-second failure/grace periods are unchanged. Grace without a current marker closes without authoritative completion. Port-only compositions can use their newest observed lifecycle marker; a consumed cursor needs the bounded lookup. No new tuning parameter, dependency or stored shape.
