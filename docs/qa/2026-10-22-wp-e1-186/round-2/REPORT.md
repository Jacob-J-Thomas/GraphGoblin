## 7. Decisions and parameters

128-event pages, 256-event / 1 MiB UTF-8 live queue, 16 KiB chunks, 256 KiB writable ceiling, 5-second drain timeout and 2-second force-close remain engineering choices from ADR-0050. Replay retains no live queue. Short-page confirmation activates live subscription handling before reading; notification follows commit, so every append is read or held. Full confirmation pages and live queue pressure return to catch-up, discard only redundant copies, and deduplicate by written seq. One writer preserves ordering and stops on backpressure. Only writable ceiling/drain timeout produces `SSE_SLOW_CONSUMER`. Durable replay is authoritative across sequence gaps. The pre-header full-log terminal scan (N5) is unchanged in asymptotic cost.

Browser batch remains 256 events / estimated 1 MiB UTF-16 JSON. The helper computes size from received text once; hook avoids serializing solely for measurement. Larger single values flush immediately, preserving payloads and complete per-run history. None of these parameters is described as owner-approved.
