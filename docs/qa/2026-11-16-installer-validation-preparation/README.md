# Windows installer baseline preparation

This test-only packet carries the sealed native installer driver and hosted supervisor for #436. The first attempt, [CI 43799391366](https://github.com/Jacob-J-Thomas/GraphGoblin/actions/runs/43799391366/job/133075561392), stopped during source-shortcut fixture creation with `WriteAppId` HRESULT `0x80070002`, before any installer case ran (0/32). The build and ordinary native launcher acceptance passed. See the original [driver packet](raw/native/README.md.txt), [execution packet](raw/execution/README.md.txt), and [byte-copy inventory](source-copy-map.json).

The first attempt also exposed two observer bugs: the classic process GUID is in `ExtendedTracingInfo/EventGuid`, and sorting ordered dictionaries needs explicit value expressions. Separate offline corrections matched both canaries and nine complete process lifetimes in the short failed setup window. They provide no installer-matrix result. The original raw artifact is retained as artifact 14195238640, SHA-256 `27c3c8f71de948fac7c028130c722a6b930dfaa5357603863ab71b387a7afb88`.

The current temporary carrier restores the ordinary Windows workflow and appends one bounded two-case COM diagnostic. It creates disposable Unicode and ASCII shortcut names, records their exact post-save file state, then captures each property-store operation's HRESULT. It runs no installer matrix. The ordinary build, native launcher acceptance and other CI jobs remain intact. See the [reviewed probe](raw/com-probe/README.md.txt) and its [byte-copy inventory](com-probe-source-copy-map.json). Diagnostic completion means the observations were recorded, including any COM failure; it does not mean installer acceptance.

Both carriers are temporary. Preserve their raw evidence and remove the diagnostic steps before final publication. Product implementation and formal review remain pending accepted baseline reproduction.
