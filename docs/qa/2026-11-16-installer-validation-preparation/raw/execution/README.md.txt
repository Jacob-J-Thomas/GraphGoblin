## Native process observation

`ProcessTrace.cs` calls `StartTraceW` with a uniquely named sequential `EVENT_TRACE_SYSTEM_LOGGER_MODE` session enabling classic process events. It uses that exact returned handle for query and its single stop attempt. The session is capped at 32 MiB. The supervisor uses the classic Process provider GUID and process-start opcode 1, with process end opcode 2 for descendant lifetime checks and rundown excluded. It uses installed native `tracerpt.exe` XML decoding, preserves the raw ETL, decoded XML, decoder schema and summary, and validates the observed named payload fields before using them. This avoids relying on the unrelated modern manifest provider for command-line fields. [System logger mode](https://learn.microsoft.com/en-us/windows/win32/api/evntrace/nf-evntrace-starttracew) · [Classic Process types](https://learn.microsoft.com/en-us/windows/win32/etw/process) · [Classic payload](https://learn.microsoft.com/en-us/windows/win32/etw/process-typegroup1) · [Native decoder](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/tracerpt)
