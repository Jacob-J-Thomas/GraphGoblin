## 7. Decisions and parameters

- The six priorities and later-within-class rule implement the supplied decision; no boundary-specific override table remains in Codex. The adapter and engine use the same exported pure fold.
- A recording error is diagnostic data. It cannot change cause, resumability or the current logical turn. Retry intent is typed provenance rather than an untyped diagnostic parsing/recovery path.
- Observed acceptance prevents a safe resend even if its append fails; only durable acceptance authorizes an inherited authored conversation under D-022. Failed positive-acceptance persistence still fails conservatively.
- Initial intents and safe retries use the same guard as repairs. Four red tests established the adjacent initial-append loss before this generalization.
- `test:prompt-evidence` selects a free port in 5660-5669 and retains disposable `gg-wp-f4-` stores/logs. Its five requested audit derivatives plus the extra follow-up are replayable after `pnpm build`. The eight sustained-read controls restore storage and use public manager recovery; their original deadline observations remain intact.
- `driver-provenance.json` records original auditor byte hashes and final maintained-driver byte hashes. The `audit-*.mjs.log.txt` snapshots are sanitized UTF-8 with LF normalization and do not claim the original raw-byte hashes. The artifact manifest hashes the final files actually retained here.
- Full API coverage uses one worker, a `gg-wp-f4-` outer temporary root and a verification-only listener allocation preload. The preload constrains Node's transport allocation, not GraphGoblin internals; [environment](api-environment.json) and [preload source](port-scope.cjs.log.txt) disclose it.
