When two rows claim the same physical record, neither may move or remove it while that conflict exists. An explicit edit that leaves one unique route on the record’s port permits that route to claim it. A newly acquired record stays on that port during the acquiring edit. The saved device data cannot identify which row originally drew a connection after its historical ownership became ambiguous. The editor uses current authored ports and preserves manual geometry throughout the ambiguous edit.
