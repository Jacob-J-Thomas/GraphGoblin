## Finite probes chosen
All probes call the public `observeExpression`. I checked each against the patched `jsonata.js`, `expression.ts`, the compiled `dist/expression.js` and the existing tests.
1. **Ordinary:** `a + b` over `{a:1,b:2}` at default limits returns `{ok:true, value:3}`.
2. **Wide siblings:** a JSON literal with a 250-item array and a 250-member object, wider than the default depth of 200, must come back unchanged. This one wasn't in your required list. I added it because it catches a patch that keeps the hooks but loses the sequential-sibling change. It compares JSON text because jsonata builds objects without a prototype, so a strict `deepEqual` would fail.
3. **Depth:** `'1'` with `{maxDepth:0}` gives reason `depth`, an `ExpressionError`, and the message `expression exceeded max depth 0`.
4. **Time:** `'1'` with `{timeoutMs:-1}` gives reason `time` and the message `expression exceeded -1ms`. The existing test at line 292 already shows this gives reason `time`.
5. **Fresh:** `'1'` again at default limits, the same cached source, gives `{ok:true, value:1}`.

Without the patch the hooks are never attached, so probes 3 and 4 would succeed and fail their assertions straight away instead of hanging. The restrictive options exist only in the probe; the 2000 ms / 200 defaults are unchanged.
