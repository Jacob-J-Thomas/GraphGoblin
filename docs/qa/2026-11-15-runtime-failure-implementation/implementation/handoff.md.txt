## Implementation

- Context Mutation maps known authored expression, predicate, Liquid render, validation and RFC 6902 target failures to nonresumable MUTATION_ERROR. The public detail has zero-based operationIndex, operationKind and cause code/message. The inspector message uses a one-based operation number and identifies a patch cause. The cause text is capped at 1,000 UTF-16 code units. The iterator and RepairRequest retain the authored index and operation across pauses. Only a successful node's patch reaches the durable node completion. Unexpected model resolution/completion throws, including the same exception class, stay outside authored classification. Schema mismatch, unavailable repair, fallback and timeout follow their existing paths. A final invalid thread reaches the existing nonresumable manager boundary, and a later operation can restore a valid intermediate thread.
- A recognized authored Exit return evaluation fault yields EXPRESSION_ERROR with node and bounded cause. The depth guard is exercised with the 230-level literal, and serialization remains outside the authored boundary. The actual executor still determines deadline and cancellation.
- The manager uses one safe projection for its event-first failure append and failure row. Engine-owned safe public copies come from the classifier, invariant, inference and child forwarding paths. Arbitrary typed internal error messages and details cannot opt into that projection via stored data. Ordinary outer and handler faults, final validation and mapping faults log raw diagnostics with available identities. The manager keeps durable script classification before appending the public result. Existing decision-provider fixed message and allowlisted public details stay in use with their original safe-only warn projection.
- Secondary inference logs carry run, node, turn and exact operation with the exception. Public entries carry the original operation sequence, preserving the acceptance error rethrow and retry/termination behavior. On child forwarding, only the canonical childDetails chain is followed. For internal primary failure, fixed primary text and known legacy primary name/stack are projected instead of republishing the old diagnostic. A legacy recording entry matches an exact engine shape and one of the three stable operation IDs. Other details are copied, including a tested path-shaped provider value. A historical decision-provider leaf can reconstruct fixed allowlisted copy without reusing its stored message. The old row and event bytes stay readable and intact.
- The contract enum, generated OpenAPI and generated API client include the new code. Existing server recovery code uses resumability. The existing inspector display renders code/message and authoritative recovery. ADR-0080, the node catalog, execution engine and CHANGELOG describe the boundary. The generator also ran both references, whose bytes are unchanged.
