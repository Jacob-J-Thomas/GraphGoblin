## Reproduce

Use the named clean checkout with dependencies and required build outputs present, project Node v22.23.4 first on PATH, and an external disposable location for this script. Pass an installed unsupported Node binary as a further argument. An already-installed below-floor Node 22 can also be supplied to establish native floor refusal.

```powershell
$candidate = '<clean checkout>'
$runner = '<external>/verify-463-correction.mjs'
$claude = (Get-Command claude.exe).Source
node $runner $candidate $claude '<installed unsupported major binary>' '<installed below-floor binary>'
```
