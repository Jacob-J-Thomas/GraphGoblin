## 7. Decisions and parameters

| State/event                              | Protection / eligibility lifecycle                                                                                                                                              |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| New or live dynamic template with no use | Retain unknown obligation until actual resolution or terminal state; future thread-dependent output is not statically bounded. No new consent.                                  |
| Live literal template                    | Resolve its trimmed physical path outside locks; protect equal, containing or contained directories only. Empty literal cannot produce a workspace.                             |
| Terminal template without use            | No future-use obligation, for success/failure/cancel/exhaustion and migration alike; retained run/history remains present.                                                      |
| Resume                                   | Restore pending future use if no recorded workspace exists; recorded uses persist and continue protecting their physical paths. Existing component approval revocation remains. |
| Recorded path has a resolution error     | Unknown/keep, including terminal runs: an actual path can still require retained files.                                                                                         |
| Configured data directory is aliased     | Resolve once to the physical root; police links and creation identities inside that root. External alias retargeting does not redirect this instance's managed operations.      |
| Confirm / withdraw / cancel              | Explicit selection and server preview unchanged. Success clears selection, focuses the persistent count and announces the result; cancel preserves selection and opener focus.  |

Capacity port/fs.statfs, pressure thresholds (enter below min(1 GiB, 5%); exit at min(2 GiB, 10%)), 60-second measurement interval, 2,048-reference/32-observation refresh bounds, 20-root/500-record history bounds, 256-candidate/32-inventory cleanup bounds and the artifact proof budget are unchanged.
