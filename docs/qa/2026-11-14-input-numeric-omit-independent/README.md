## Reproduce

Copy the gateway, browser driver and configs to an external disposable directory. Use the exact built checkout and project Node, then start `node gateway.mjs <checkout> <head>` to record the loopback URL. Open the app with Playwright CLI in separate named sessions using `desktop.edge.json` and `touch.edge.json`. Snapshot each, then call `run-code --filename=verify-numeric-omit.playwright.js`. Read the result JSON for each profile. Close both named sessions and send a line to the gateway's stdin.

The gateway and two Edge PIDs were absent after cleanup, all fixture locks were gone and the candidate remained clean. [Cleanup](cleanup.json) · [Final gateway identity](gateway-closed.json)

This evidence covers the two exercised native Windows profiles, including Edge's coarse input emulation. Independent review, current-head CI, the exact-head audit and owner closure remain separate.
