## P1 · A reserved member in a row’s JSON Value disappears before validation

In the built web editor, I opened the inference node’s **Settings → Advanced → Config overrides**. I used the existing `example` row, its JSON **Value** control, and a separate `neighbor` row. Each reserved member held the boolean `false`. I observed the editor, its actual autosave bodies, and a fresh HTTP GET of the stored draft. The browser used an isolated session and the gateway used a synthetic in-memory store.

| Input in the Value control | Browser and gateway observation |
| --- | --- |
| An ordinary object with `marker` and `survivor` | The editor saved it, and GET returned the exact object. |
| A table containing `"bad key": false` | The editor displayed a schema error, retained the typed text, sent no autosave for that edit, and GET returned the preceding valid draft. Correcting it restored normal autosave. |
| `{"marker":"reserved-changed","__proto__":false,"survivor":true}` | The editor sent a PUT containing only `marker` and `survivor`. It showed **All changes saved** without a blocking issue. GET returned the same altered object. |
| `{"marker":"array-changed","rows":[{"__proto__":false,"enabled":true}]}` | The PUT and GET contained only `enabled` inside the array element. Closing, reloading, and reopening the node displayed that altered value. |

The neighboring row remained intact. The loop stayed unpublished. Sending the unmodified reserved-member input directly through the draft API returned HTTP 400 `MALFORMED_BODY` and left the complete prior draft unchanged. On the editor path the backend received a different, valid document. The first browser observation sampled an intermediate corrected control before autosave settled. I retained it, then repeated the checks with explicit server readback and a saved-state check for every valid marker. The confirmation recorded four autosaves and their bodies. The public-safe observation file has SHA-256 `239798fc6c3d615a52a99baf547c6cd531526d14d1c674bcdd24b065c97fceb6`. [Browser observations and exact inputs](editor-value-observations.json)

**Cause and scope.** `RecordValue` sends the entry to `JsonControl`, whose `JsonText` forwards the parsed value without the enclosing override-key rule. The form clones and cleans the value before `SchemaForm` validates it. Its `stripUnset` copy writes members onto a normal object and loses this literal own member. The installed form library’s normal object-copy path also uses assignment to copy own keys. The subsequent whole-configuration check no longer sees what the author typed. This normalization predates the PR. The PR introduces a raw-key contract and promises consistent refusal in this authoring path. Its new tests cover the structured Key, a nested space key, and whole-section JSON. They leave this row-Value case open. Earlier issue #521 covers feedback on an already detected error. Here the missing diagnostic is accompanied by a successful altered write. [RecordValue](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/053015f93f7d106435bed7ffa052e1938e3d1d85/apps/web/src/forms/fields/structure.tsx#L802) · [JSON Value editor](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/053015f93f7d106435bed7ffa052e1938e3d1d85/apps/web/src/forms/fields/json.tsx#L529) · [Validation order](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/053015f93f7d106435bed7ffa052e1938e3d1d85/apps/web/src/forms/SchemaForm.tsx#L293) · [Form copy](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/053015f93f7d106435bed7ffa052e1938e3d1d85/apps/web/src/forms/unset.ts#L13) · [Acceptance criterion](https://github.com/Jacob-J-Thomas/GraphGoblin/issues/429)

**Acceptance condition.** At the actual structured Value input, retain the complete invalid text and identify the offending nested member before any operation can erase it. A refused object or table inside an array must leave the last valid server draft exact, including valid siblings and neighboring rows, with no successful autosave of a narrowed value. A corrected edit must clear the refusal, save the exact intended definition, and survive reload. Preserve the existing structured-Key and whole-section JSON behavior. Exercise both failing shapes and a valid control through the built editor.
