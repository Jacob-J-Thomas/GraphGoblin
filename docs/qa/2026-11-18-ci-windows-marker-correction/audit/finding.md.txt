## Blocking finding

**P2. The Windows exporter accepts a non-string rejection-marker type.** The published contract requires every observation field to have its declared type. The validator for `rejected.recordType` uses `Object.hasOwn`, which converts its argument to a property key. The recorder uses the same lookup and retains the original value in its marker. The observation reader relies on the validator, and finalization includes the observation file whenever the reader accepts it. A structured value can therefore survive in a field that downstream readers are entitled to treat as a string. This is an introduced #496 artifact-contract defect. The archive inspected from the actual failed native run contained one correctly typed rejection marker. [Field validator](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/4d2743c2cefaea971d3bdc3ab10e9fdd9bda3523/tooling/scripts/windows-launcher-evidence.mjs#L206), [recorder](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/4d2743c2cefaea971d3bdc3ab10e9fdd9bda3523/tooling/scripts/windows-launcher-evidence.mjs#L746), [reader](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/4d2743c2cefaea971d3bdc3ab10e9fdd9bda3523/tooling/scripts/windows-launcher-evidence.mjs#L1181), [artifact selection](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/4d2743c2cefaea971d3bdc3ab10e9fdd9bda3523/tooling/scripts/windows-launcher-evidence.mjs#L1394)

On Node 22.23.4, the public in-memory validator accepted both the genuine hosted marker and a boxed field whose JavaScript type was `object`. These two controls serialize identically. A separate ordinary dictionary check confirmed that property-key conversion also accepts a structured value whose JSON representation retains its structure. The artifact consequence follows from the reviewed reader and selection code. The finding makes no claim of secret disclosure or a false native test pass. Require a primitive string in both lookups, normalize invalid incoming type names to `unknown`, and add a regression covering the string contract at write and read time. [Type-check receipt](type-check.json), [ECMAScript property-key conversion](https://tc39.es/ecma262/multipage/fundamental-objects.html#sec-object.hasown)
