## F3 · P2 · A proved turn start refusal can wait indefinitely for filesystem metadata

The normal turn dispatch passes `timeoutMs: null`. An inference node’s watchdog is optional, and the loop’s default run deadline is null. Under these supported defaults, the runner installs no timer for the turn. When the child emits an error without a PID, the runner records the refusal, starts the filesystem observation and postpones `finish(null)` until the observation resolves. The subsequent child close explicitly returns while a refusal is recorded. If a metadata read remains pending, the caller receives neither the failure nor its definite non-submission status. The run can remain active until the read returns or someone cancels it. On the target branch the error handler completed the failed start immediately. [Turn dispatch](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/580aded6d295061897b047ac16811e5da230d9e0/packages/infrastructure/src/claude/harness.ts#L509-L525) · [Watchdog default](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/580aded6d295061897b047ac16811e5da230d9e0/packages/contracts/src/nodes.ts#L401-L409) · [Run deadline default](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/580aded6d295061897b047ac16811e5da230d9e0/packages/contracts/src/loop.ts#L46-L55) · [Watchdog implementation](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/580aded6d295061897b047ac16811e5da230d9e0/packages/engine/src/handlers/common.ts#L147-L154) · [Runner timer](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/580aded6d295061897b047ac16811e5da230d9e0/packages/infrastructure/src/claude/process.ts#L170-L178) · [Current refusal and close](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/580aded6d295061897b047ac16811e5da230d9e0/packages/infrastructure/src/claude/process.ts#L229-L247) · [Target behavior](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/4cec0f9bbe34f2ae13e4e38182c033b799c19f3f/packages/infrastructure/src/claude/process.ts#L161-L169)
