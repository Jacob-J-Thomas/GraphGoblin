## 7. Decisions and parameters

| Parameter / policy             | Choice and reason                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Replay page                    | **128 events**, one constant. Measured ~470-byte events give ~60 KiB/page; bounded read count without a query per event. Release the previous page and yield between pages. Individual supported event size remains intrinsic.                                                                                                                                                                                                                                                           |
| Held server live handoff       | **256 events and 1,048,576 encoded UTF-8 bytes**. Count limits tiny events, bytes limits large ones; overlap with durable replay is deduplicated by sequence. Overflow fails and reconnects from durable history rather than dropping events.                                                                                                                                                                                                                                            |
| Write chunk / writable ceiling | **16,384-byte chunks; 262,144 normal queued bytes**. Stop on false, await drain before writing more. Chunking preserves supported large payloads; the ceiling protects composition roots with larger high-water marks. The one small problem control may queue beyond the normal ceiling.                                                                                                                                                                                                |
| Slow-consumer time / lifetime  | **5,000 ms without drain** triggers `stream.error` / `SSE_SLOW_CONSUMER` (503); count/byte overflow or a live sequence gap also triggers it. End the stream, unsubscribe and clear held buffers; force destroy after **2,000 ms** if a peer never reads. A transport that cannot carry its own control is reported as premature EOF/network failure; helper retries from its last complete delivered event. Tests shorten drain timeout through the public option, not private mutation. |
| Cursor and partial frames      | `id` follows data. Failure makes a partial frame invalid, resets its id to the last complete event and then sends the typed problem. It preserves an already accepted complete frame. Negative/fractional numeric headers retain exclusive integer-sequence behavior. Controls never advance the client cursor.                                                                                                                                                                          |
| Client reporting               | Reuse `GraphGoblinApiError`; report slow failure via `onError` before existing backoff, retry from last delivered seq, respect finite maxAttempts. Fatal stored-history controls reject `done`; no infinite repair loop. Abort directly cancels the body reader.                                                                                                                                                                                                                         |
| Browser held batch             | **256 events / estimated 1 MiB UTF-16 JSON**, flushed before crossing a byte boundary; one larger event flushes immediately. This bounds temporary waiting batches while keeping payload/history intact. Error shows one-sentence reason until reopened.                                                                                                                                                                                                                                 |

These are engineering choices, not owner-approved values. No new dependency or migration.
