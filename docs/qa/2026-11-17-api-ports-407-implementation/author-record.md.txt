## Scope and gates

The allocator coordinates callers within one API Vitest run. The helper owns a claim by numeric port while key creation, startup, restarts and cleanup proceed. The operating system bind probe skips ports with established listeners and closes before the API starts. Concurrent runs use disjoint assigned ranges. The separate acceptance scripts and tests that let the OS assign an ephemeral port have their own allocation methods.
