## Reproduction

With a clean checkout at the recorded candidate and the matching build, run `node gateway.mjs <worktree> <head>` in a disposable directory outside the repository. Copy `gateway.mjs`, `desktop.edge.json`, and `verify-names.playwright.js` there first. Open the reported origin with `playwright-cli -s=gg209-independent-ui open <origin>/app/ --config=desktop.edge.json`, then use `playwright-cli -s=gg209-independent-ui run-code --filename=verify-names.playwright.js`. Require all six outcomes and `failure: null` in the result. Close the named browser session and send a line to the gateway process to shut it down.

The native run covered the built main web shell in isolated headless Windows Edge with one local owner.
