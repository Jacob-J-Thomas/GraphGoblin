## Reproduce

Copy the gateway and Playwright files to an external disposable directory. Use the built candidate with Node v22.23.4, Edge and Playwright CLI. Start `node gateway.mjs <checkout> <head>` to record the loopback URL. Open the app in a named Playwright CLI session with the corresponding `desktop.edge.json` or `touch.edge.json` config. Snapshot the app and run `run-code --filename=verify-input.playwright.js`. Close each named session and send a line to the gateway's stdin.

All four recorded Edge PIDs and the gateway PID were absent after shutdown. The fixture lock was gone and the candidate stayed clean. [Cleanup](cleanup.json) · [Final gateway identity](gateway-closed.json)
