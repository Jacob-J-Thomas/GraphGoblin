# #41 responsive sweep and the #11 light-theme tuning: screenshots

Date: 2026-10-05. The real app, built with `pnpm build` and served by `apps/web/e2e/server.ts` (the in-memory API with the fake harness), photographed in Edge with reduced motion so pulses hold still. Every screen and state at 360 by 780, 768 by 1024, 1024 by 768, and 1440 by 900 px in both themes; Settings as a full-page shot.

- `dark/` and `light/`: the app after the sweep, Dark (the default) and Light chosen the way Settings → Appearance does (the stored theme, shown by the boot script before first paint).
- `before-light/`: Loops, the editor, the run inspector, and Settings at 768 and 1440 px in Light before the tuning (a build of `cb46771`, the feature branch before this work). The seed then had no API key yet, so its Settings shows none; that is data, not design.

Regenerate with `pnpm build` and `pnpm --filter @graphgoblin/web capture:screens` (`GG_CAPTURE_SET=before` on a build of an earlier commit for the before set; `GG_CAPTURE_ONLY`, `GG_CAPTURE_WIDTHS`, `GG_CAPTURE_THEMES`, and `GG_CAPTURE_OUT` narrow or redirect a run; see `apps/web/e2e/screens.capture.ts`).

## What the sweep changed, in short

- **Tables** (Loops, Runs, Events below 1024 px; the model catalog and classifier models below 768 px) stack each row into a block, each value under its column's name. Before, they scrolled sideways inside their cards with no sign that they did, cutting off Loops' actions at 768 px and Events' columns at 360 and 768 px.
- **Forms** become one column below 640 px (Runs filters, Loops create, Settings' forms, the API key panel).
- **The editor**: the toolbar wraps instead of pushing Publish off the screen at 360 px; the expanded loop settings (below 1024 px) and palette (below 768 px) float over the canvas instead of squeezing it to 188 px at 768 px or pushing the page sideways at 360 px.
- **Touch**: 44 px controls where the pointer is coarse (not visible in these mouse-pointer shots; covered by `e2e/responsive.spec.ts`).
- **Light theme** (#11): white page; cards, panels, the toolbar, and dialogs on a warm tint (brown-50) with head bands and table heads a step deeper (brown-100, brown-75); titles in dark brown (brown-900) and column headers in brown-700; warm hairlines and darker brown control edges. Dark is unchanged.
- **Smaller fixes**: Loops shows the update time under the name; the run's patch diff stacks on narrow screens; the 404 route has a heading and a way back; the API key panel's field keeps a readable width; the cron builder's summary says what to choose instead of reading with a gap.
