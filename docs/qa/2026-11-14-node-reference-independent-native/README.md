## Reproduce

Copy the gateway, Edge config and one browser runner to a disposable directory outside the repository. From there, start `node gateway.mjs <frozen-worktree> <head>`. The gateway validates the clean commit and served assets and returns the isolated origin. Open `<origin>/app/loops` in the named `gg273-independent-native` Playwright CLI session with `--config=desktop.edge.json`, then invoke `run-code --filename=verify-rename-attempt3.playwright.js` for the recorded first four outcomes. Open `<origin>/app/loops?qa-scenario=chat-only` and invoke `run-code --filename=verify-rename-attempt4.playwright.js` for Chat. The attempt 4 script also runs the complete matrix when the query parameter is absent. Inspect the structured result and close the named session and gateway to release the store.

This run covered the main web shell in isolated headless Edge and used read-only IndexedDB inspection for device evidence. It used a synthetic Chat draft through the ordinary public route.
