## Defects

### QA-01 — Minor: readiness documentation contradicts background/offline behavior and zero-probe drafts

Steps: load Settings with ready fakes; go offline and choose Retry preflight. Separately, close the browser, set both fakes to hang, and create/import/save drafts while counting CLI `--version` calls. Also run the readiness browser spec's failed-refetch case.

Expected: documentation distinguishes first load, background recheck, paused offline request, failed request, and draft writes using the observed behavior.

Actual: Settings retains Ready badges offline with “Offline; showing the last check.” A failed request replaces its list with “Could not load preflight”, without an Unknown badge. Draft writes invoke no probe. These exact sentences mismatch those observations:

The later card paragraph correctly describes the exception. |
