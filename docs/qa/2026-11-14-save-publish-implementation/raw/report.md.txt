**What changed:**
- **New `usePublish.ts`:** publishing now runs in the editor's save queue, and every barrier is rechecked just before the POST.
- **Notice copy:** the notice compares the version the server actually stored with the draft it acknowledged for this attempt, and says nothing about who wrote a different draft.
- **Lost or failed replies:** these are read back before anything is claimed. If that check also fails, the next Publish checks the server before sending anything.
- **List and loop detail:** these are refreshed after every accepted save, including the save sent on leaving the editor, and an older read can't overwrite the result.
- **Base token:** a leaving save uses only its own editor load's token, or is skipped if that load was replaced.
