# Verification and delivery handoff · revision 03

## Per-site external controls

Use isolated public-method fixtures with one fault at a time and no unrelated timeout/abort unless specified. For each evaluator-adjacent external call compare (a) a true domain `TemplateError` or `ExpressionError`, (b) a plain Error with the same name, (c) a plain object with the same code and message. No one of these is authored by virtue of that spelling. The table distinguishes what can already be public. For the harness, use the caught error's string `code` or current default `HARNESS_TURN_FAILED` as `adapterCode`; retain the current text from `describeError`. Generic family eligibility **H** means `harness === "codex" || evidence.retriable === true` for an unpinned failure. **U** means the pending task has a usable session under `canContinueTurn` (an inherited authored handle alone lacks durable acceptance). **D** = definitely-not-submitted, **Q** = delivery-uncertain. A retained earlier higher-ranked observation wins; positive/observed acceptance prevents a later D downgrade.
