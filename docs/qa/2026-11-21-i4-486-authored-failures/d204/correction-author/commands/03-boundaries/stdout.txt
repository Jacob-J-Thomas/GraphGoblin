# ADR-0088 - Authored failures at execution boundaries

Status: Selected under delegated coordinator decision D188. Consolidated owner decision review is pending.

## Context

A loop pins its definition for the run. An internal-error message gave an author little way to find a failing template or expression, and Resume could repeat a probe, context-file write or provider action before encountering the same field again. The evaluator also serves callers that can supply JavaScript bindings. A library exception and one thrown by a binding can have identical messages, codes and object identities. [Issue and plan](https://github.com/Jacob-J-Thomas/GraphGoblin/issues/486#issuecomment-7061825658)

## Decision

Project errors at the selected concrete evaluation sites on pinned source and inert run data. A single JSONata evaluation produces a value or its original rejection plus a finite observation of the phase that failed. Parsing and regex safety describe the top-level source. A rejected runtime string in `$eval` receives the ordinary evaluation direction. Per-invocation hook identity establishes a winning depth or time limit. Binding preparation and predicate coercion carry no authored fact.

Use a fixed field, a bounded cause and corrective action in the existing error codes. Report one-based ordinals for people and zero-based indices in details. Names, paths, runtime values and literal `$error` arguments are excluded from the new copy. At these newly typed JSONata sites the evaluator's own message is neither published nor logged. Existing Mutate and Exit failures can expose bounded authored text, including an expression's message. That historical policy differs from the fixed inference-transform and subloop messages selected here. Decision-route evaluation and request-side signal rejection retain their established projections.

A deterministic fault in a pinned field refuses Resume. Workspace templates render and trim in the engine before the filesystem port resolves a fixed or temporary directory. A failed terminal file return uses the existing channel receipt. A parent mapping failure keeps the real terminal child completion. Child-failure links belong to an actual failed child.

Preparation can preserve previous task evidence without recording a new intent. Only the winning repair-prompt or transform fault after a provider result reports that result in its public message and phase. Existing acceptance, uncertainty, cleanup, cancellation and timeout rules determine the last actual turn and the winning cause. Publication uses the existing failure row and event. Historical data remains readable with its original text and recovery state.

## Alternatives considered

Publishing a guarded literal would require an additional AST-shape contract and would help only a narrow form of an expression that always fails. A process-wide error marker or class/code mapper could misattribute a rethrown error from another call. Automatic retry would repeat work from earlier successful steps. The selected approach keeps diagnostics local to the operation and preserves observed effects.

/** An explicitly returned native candidate stays authoritative, including undefined or null. */
function outputCandidate(result: HarnessResult): unknown {
  return Object.hasOwn(result, 'structured') ? result.structured : jsonOrText(result.finalText);
}

function noteFor(item: HarnessItem): string | undefined {
  switch (item.type) {
    case 'command':
      return `Ran: ${item.summary}`;
    case 'file-change':
      return `Changed: ${item.summary}`;
    case 'tool-call':
      return `Tool: ${item.summary}`;
    default:
      return undefined;
  }
}

/** A run manager over fake ports with helpers for scenario tests. */
export interface TestEngine {
  ports: FakePorts;
  manager: RunManager;
  settings: EngineSettings;
  /** Register a published version. The loop id is derived from the name unless given. */
  publish(
    def: LoopDefinitionInput,
    options?: { loopId?: string; version?: number; status?: 'draft' | 'published' },
  ): LoopVersionRecord;
  /** Start a run from a manual trigger. */
  start(loopId: string, payload?: JsonValue, extra?: Partial<StartRunInput>): Promise<RunRecord>;
  /** Start a run and wait until the manager is idle. Returns the final record. */
  runToIdle(
    loopId: string,
    payload?: JsonValue,
    extra?: Partial<StartRunInput>,
  ): Promise<RunRecord>;
  /** Wait for idle and fetch the run. */
  settle(runId: string): Promise<RunRecord>;
  events(runId: string): RunEvent[];
  eventTypes(runId: string): string[];
  loopId(name: string): string;
}

export async function createTestEngine(
  overrides: Partial<EngineSettings> = {},
  portOptions: { secrets?: Record<string, string>; handlers?: HandlerRegistry } = {},
): Promise<TestEngine> {
  const ports = createFakePorts(portOptions);
  const settings: EngineSettings = { ...DEFAULT_TEST_SETTINGS, ...overrides };
  const manager = new RunManager(ports, settings, portOptions.handlers);
  await manager.start();
  const loopId = (name: string): string => fakeUlid(`loop:${name}`);
  const engine: TestEngine = {
    ports,
    manager,
    settings,
    loopId,
    publish(def, options = {}) {
      const parsed: LoopDefinition = LoopDefinitionSchema.parse(def);
      const id = options.loopId ?? loopId(parsed.name);
      const version = options.version ?? 1;
      const record: LoopVersionRecord = {
        id: fakeUlid(`version:${id}:${version}`),
        loopId: id,
        version,
        status: options.status ?? 'published',
        definition: parsed,
        createdAt: '2026-10-02T11:00:00.000Z',
        ...(options.status === 'draft' ? {} : { publishedAt: '2026-10-02T11:00:00.000Z' }),
      };
      ports.loops.add(record);
      return record;
    },
    start(id, payload = null, extra = {}) {
      return manager.startRun({
        ownerId: 'local',
        loopId: id,
        source: 'manual.api',
        payload,
        ...extra,
      });
    },
    async runToIdle(id, payload = null, extra = {}) {
      const run = await engine.start(id, payload, extra);
      return engine.settle(run.id);
    },
    async settle(runId) {
      await manager.waitForIdle();
      const run = await ports.runs.get(runId);
      if (!run) throw new Error(`run ${runId} vanished`);
      return run;
    },
    events(runId) {
      return ports.events.all(runId);
    },
    eventTypes(runId) {
      return ports.events.all(runId).map((e) => e.type);
    },
  };
  return engine;
}

export function singleNodeLoop(
  name: string,
  testNode: TestNode,
  exitConfig: Record<string, unknown> = {},
): LoopDefinitionInput {
  const node = testNode as unknown as LoopDefinitionInput['nodes'][number];
  const extraEdges =
    node.kind === 'decision'
      ? []
      : [{ id: 'e2', from: { node: node.id, port: 'out' }, to: { node: 'done' } }];
  return {
    schemaVersion: CURRENT_DEFINITION_FORMAT,
    name,
    nodes: [
      { id: 'start', kind: 'trigger', label: 'Start', config: { type: 'manual' } },
      node,
      { id: 'done', kind: 'exit', label: 'Done', config: exitConfig },
    ],
    edges: [
      { id: 'e1', from: { node: 'start', port: 'out' }, to: { node: node.id } },
      ...extraEdges,
    ],
  };
}
import type { PromptProvenance, RunEvent, TurnSubmission } from '@graphgoblin/contracts';
import type { NodeContext } from '../handler.js';
import type { HarnessEvent } from '../ports.js';
import { RunFailureError } from '../errors.js';

type Turn = Extract<RunEvent, { type: 'harness.turn' }>;
type FreshSession = NonNullable<Extract<RunEvent, { type: 'run.resumed' }>['freshSession']>;
export interface PendingTurn {
  turn: Pick<
    Turn,
    'visitId' | 'turnId' | 'prompt' | 'promptKind' | 'resumeSessionId' | 'harness' | 'context'
  >;
  submission: PromptProvenance['submission'];
  sessionId?: string;
  accepted: boolean;
  acceptanceObserved?: boolean;
  intentUnconfirmed?: boolean;
}

/** The first start since this node last finished identifies one visit across retries/restarts. */
export function visitTurn(
  events: readonly RunEvent[],
  nodeId: string,
): {
  visitId: string;
  pending?: PendingTurn;
  completedVisits: number;
  completedAttempt?: number;
  freshSession?: FreshSession;
} {
  let visitId = '';
  let pending: PendingTurn | undefined;
  let completedVisits = 0;
  let attempt: number | undefined;
  let completedAttempt: number | undefined;
  let freshSession: FreshSession | undefined;
  for (const event of events) {
    if (
      event.type === 'run.resumed' &&
      event.freshSession?.nodeId === nodeId &&
      event.freshSession.visitId === visitId
    ) {
      freshSession = event.freshSession;
      pending = undefined;
    }
    if (event.type === 'run.failed' && event.failure.nodeId === nodeId) {
      const evidence = event.failure.inference;
      if (evidence?.visitId === visitId) {
        // Terminal provenance survives a failed classification append. An uninvoked task
        // also carries its exact intent if a read could not resolve an ambiguous append.
        if (evidence.retry && evidence.submission === 'definitely-not-submitted')
          pending = {
            turn: {
              visitId,
              turnId: evidence.turnId,
              promptKind: evidence.promptKind,
              ...evidence.retry,
            },
            submission: evidence.submission,
            accepted: false,
            ...(evidence.sessionId ? { sessionId: evidence.sessionId } : {}),
          };
        else if (pending?.turn.turnId === evidence.turnId) {
          pending.submission = evidence.submission;
          if (evidence.sessionId) pending.sessionId = evidence.sessionId;
        }
      }
    }
    if (!('nodeId' in event) || event.nodeId !== nodeId) continue;
    if (event.type === 'node.finished') {
      // Durable completion, not a locally finished session row, advances continuity/reset.
      completedVisits += 1;
      completedAttempt = attempt;
      visitId = '';
      pending = undefined;
      freshSession = undefined;
    }
    if (event.type === 'node.started') {
      attempt = event.attempt;
      if (!visitId) visitId = event.runId + ':' + event.seq;
    }
    if (event.type === 'harness.turn' && event.visitId === visitId) {
      pending = {
        turn: {
          visitId: event.visitId,
          turnId: event.turnId,
          prompt: event.prompt,
          promptKind: event.promptKind,
          harness: event.harness,
          ...(event.context ? { context: event.context } : {}),
          ...(event.resumeSessionId ? { resumeSessionId: event.resumeSessionId } : {}),
        },
        submission: 'delivery-uncertain',
        accepted: false,
        ...(event.resumeSessionId ? { sessionId: event.resumeSessionId } : {}),
      };
    }
    if (pending && event.type === 'harness.session') pending.sessionId = event.sessionId;
    if (pending && event.type === 'harness.submission' && event.turnId === pending.turn.turnId) {
      pending.submission =
        event.submission === 'submitted' ? 'delivery-uncertain' : event.submission;
      pending.accepted ||= event.marker !== undefined;
    }
  }
  return {
    visitId,
    completedVisits,
    ...(completedAttempt === undefined ? {} : { completedAttempt }),
    ...(pending ? { pending } : {}),
    ...(freshSession ? { freshSession } : {}),
  };
}

export function provenance(pending: PendingTurn): PromptProvenance {
  return {
    visitId: pending.turn.visitId,
    turnId: pending.turn.turnId,
    promptKind: pending.turn.promptKind,
    submission: pending.submission,
    ...(pending.sessionId ? { sessionId: pending.sessionId } : {}),
    ...(pending.intentUnconfirmed
      ? {
          retry: {
            harness: pending.turn.harness,
            prompt: pending.turn.prompt,
            ...(pending.turn.context ? { context: pending.turn.context } : {}),
            ...(pending.turn.resumeSessionId
              ? { resumeSessionId: pending.turn.resumeSessionId }
              : {}),
          },
        }
      : {}),
  };
}

export async function submission(
  ctx: NodeContext<'inference'>,
  pending: PendingTurn,
  state: TurnSubmission,
  marker?: Extract<HarnessEvent, { type: 'submitted' }>['marker'],
): Promise<void> {
  // Observed acceptance prevents a safe resend even if its append fails. Only durable
  // acceptance (accepted) authorizes continuing an inherited authored conversation.
  pending.acceptanceObserved ||= marker !== undefined;
  // Once accepted, a later refusal cannot make resending this turn safe.
  pending.submission =
    state === 'submitted' ||
    ((pending.accepted || pending.acceptanceObserved) && state === 'definitely-not-submitted')
      ? 'delivery-uncertain'
      : state;
  await ctx.services.record({
    type: 'harness.submission',
    nodeId: ctx.node.id,
    visitId: pending.turn.visitId,
    turnId: pending.turn.turnId,
    submission: state === 'submitted' ? 'submitted' : pending.submission,
    ...(marker ? { marker } : {}),
  });
  // Recovery eligibility must use durable acceptance, including if this append fails.
  pending.accepted ||= marker !== undefined;
}

/** An inherited handle alone cannot establish this authored task's conversation (D-022). */
export function canContinueTurn(pending: PendingTurn): boolean {
  return (
    !!pending.sessionId &&
    (pending.accepted ||
      pending.turn.promptKind !== 'authored' ||
      pending.sessionId !== pending.turn.resumeSessionId)
  );
}

export function recoveryFailure(pending: PendingTurn, nodeId: string): RunFailureError {
  const missing = pending.submission === 'session-missing';
  return new RunFailureError(
    missing ? 'HARNESS_SESSION_MISSING' : 'HARNESS_DELIVERY_UNCERTAIN',
    missing
      ? 'The recorded provider session is missing or refused. An explicit fresh-session choice is required.'
      : 'Prompt delivery is uncertain and no usable session was established for this task. An inherited conversation without durable acceptance cannot be continued. Use Replay from the node for a deliberate new attempt.',
    { nodeId, resumable: false, inference: provenance(pending) },
  );
}
