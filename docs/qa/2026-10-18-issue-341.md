Implemented on `codex-i341-ref-list`. GitHub was read-only: the requested `gh issue view` commands returned 401, so the public GitHub REST API supplied #341 and #38's final decision and preceding walkthrough. No GitHub writes were made.

## Scope and behavior

`apps/web/src/forms/EarlierNodeOutputs.tsx` contains the single new component, its context and small pure helpers. `NodeEditorDialog` provides the current node and live draft definition from the editor store; `StringControl` passes its existing field path through `CodeField`. The list sits after the editor/preview and reuses `Disclosure`, `HelpText` and `Button`. There are no contract, engine or API changes or dependencies.

Reverse breadth-first traversal finds all nodes with a nonempty path to the current node, orders by shortest distance then ID, and includes the current node only on a cycle, marked **previous visit**. Existing domain `reachableFrom` walks forward without distances, and the store has no reverse-distance helper. Nonwriters are omitted without interrupting traversal. An empty result renders nothing. Edges and node-ID edits update references immediately.

References are selectable, use the field's syntax and copy with `navigator.clipboard.writeText`. A polite live status says **Copied** or explains manual copying after failure. Hyphenated IDs use Liquid bracket quoting and JSONata quoted path segments; JSONata literal names `true`, `false` and `null` also need quoting. Tests render the references using the real domain LiquidJS and JSONata engines.

The new nested disclosure exposed an existing collection-focus assumption: it selected any descendant disclosure panel. `fields/collection.tsx` now selects only the row's own disclosure panel, so adding an argument still focuses its editor. The existing browser regression found this; a unit assertion also protects it.

This is interim help, not validation: a possible branch may not execute, prior-visit values are absent on the first visit, transforms or authored patches may change values, and references already typed are not repaired on rename. The sample preview is unchanged. Owner product acceptance and the orchestrator's independent review remain separate from these checks.
