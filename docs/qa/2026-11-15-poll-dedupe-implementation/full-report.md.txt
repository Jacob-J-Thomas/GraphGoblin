## #361 runtime changes

- Item preparation checks that the selected value is JSON, evaluates its key and applies the existing type, blank and 512-unit rules. That precedence preserves whole-batch refusal for an overlong key that also has a lone surrogate. An otherwise eligible malformed key yields an indexed `POLL_ITEM_REJECTED` / `MALFORMED_DEDUPE_KEY` result containing only diagnostic fields. This happens before duplicate tracking and structural-depth classification. Each repeated malformed value gets its own diagnostic. Eligible duplicated well-formed keys still fail the complete batch, including a depth-refused item with a duplicate key. The selector and all candidates still finish validation before lookup or admission can begin.
- Item admission sends one indexed read containing every exact usable candidate key, including a structurally refused candidate's well-formed key for existing silent seen-key filtering. Empty and malformed-only batches skip lookup. A malformed rejection keeps its original candidate position and never reaches admission. Seen or refused items and atomic duplicate skips consume no cap. Lookup failure still prevents all starts and an admission failure still stops the tail.
- Single-result polling validates the exact string-or-JSON identity after slicing to 512 UTF-16 code units. An ill-formed derived key logs `POLL_DEDUPE_KEY_INVALID` / `MALFORMED_DEDUPE_KEY` with the trigger IDs, then refuses the observation before `hasDedupe` and `startRun`. This includes a complete pair split by the slice. No replacement or shorter prefix is substituted. Omitted, undefined, null and empty results take their existing unkeyed admission path.
- A pure Unicode-mode surrogate-range predicate is shared by the two poll paths through the existing domain export. Complete pairs are code points outside the surrogate range. Literal U+FFFD and well-formed pairs keep their original values. Poll probe payload strings outside the derived identity retain existing behavior. No dependency, schema, migration, store rewrite, provider, webhook-intake, scheduler, engine or SQLite source changes are present.
