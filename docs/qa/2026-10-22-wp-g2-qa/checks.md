## Interpretation limits

- Real malformed requested inbound-event pages fail with a typed500 error and no cursor. They cannot be skipped in the current contract. The successful-empty-page continuation check changes only an HTTP response, retains the real cursor, and is controlled-response evidence.
- The original MCP error parser wrongly assumed every tool response was JSON. REST assertions had passed. lookahead-retest.jsonl corrects the parser and reruns only the two corruption variants, with no product change.
- The simultaneous inactive-tab click timed out in Playwright. The targeted follow-up activates each actual tab before actions and uses the same timeouts. Both tabs then reach105 unique runs. The initial timeout is retained as a browser automation limitation.
- Native API and MCP claims use built processes and real file-backed SQLite. Edge history specs use the repository fake-harness test composition with real SQLite and the built web app; they establish no paid-provider behavior.
