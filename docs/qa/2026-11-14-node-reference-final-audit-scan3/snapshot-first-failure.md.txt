# First snapshot helper failure

The first read-only snapshot attempt exited 1 on Windows. The original helper is preserved as snapshot-helper-first.mjs. No checkout/index change occurred and no snapshot identity was written.

The corrected helper reads the immutable tree once and obtains blob contents by object ID through git cat-file --batch. This avoids filename ambiguity and per-file Git processes while preserving the same complete committed-byte hash inventory. The verification scope is unchanged.
