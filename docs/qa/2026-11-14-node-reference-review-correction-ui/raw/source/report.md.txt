**How each finding failed on the old code, and the fix**
- **U1 (operation rows collapse on rename):**
  - Old code: pressing Enter collapsed the open Coerce row. Clicking the nested Source sent focus to the operations list instead of the Source input.
  - Fix: when the rename succeeds, the dialog gives the repaired config the same row ids as before. It only does this if every list kept its length, and never by matching row content. Open and closed rows now keep their state on Enter, and a click keeps focus on the new Source input. Undo and redo keep both.
- **U2 (stale review links):**
  - Old code: after removing the first operation, the notice's link focused "Third note" at index 1.
  - Fix: the rename report now keeps the draft as the rename left it. A row stays a link only while its node's config is unchanged from that draft. Otherwise it stays listed as information, and the notice says "audit changed after the rename. Its places show where they were then and no longer open a field." The counts and summary are unchanged, and undo brings the link back.
  - I chose to withdraw the link rather than follow the moved row. It is conservative: any edit to that node, even fixing the warned field itself, removes that node's links until undo.
- **U3 (held JSON lost after rename):**
  - Old code: the remount cleared the held Input JSON and added an extra undo step.
  - Fix: held section JSON is now released only by the author: typing, Apply, Cancel or discard. The 4-space formatted buffer keeps its exact text. One undo and one redo restore the whole graph and the buffer with no extra step, and redo is not erased. Apply is then an ordinary step.
  - This applies to all held section JSON. A buffer that becomes equal through a sibling fix also stays held, and it blocks Publish and editor switching until Apply or Cancel, as any held JSON does.
- **Docs:** docs/09, the guide and the CHANGELOG now separate automatic form writeback from explicit raw Apply. They give JSONata and Liquid bracket examples separately, add the direct single-presence caveat, and say which listed places open a field. I did not edit ADR-0075; it makes no conflicting claim.
