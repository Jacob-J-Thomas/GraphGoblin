The latter includes journalling and process exit after the 10-second request deadline. On Windows an IPC-controlled child calls the built API's public `app.close()`, exercising the real main/container close hooks; Windows `child.kill('SIGTERM')` would be forceful. ## 7. Decisions and parameters

- D-021 comes from the orchestrator: no new outbound attempt after stop; an existing request keeps its original deadline. Backoff wakeup does not spend budget or alter a saved retry deadline.
- Reviewed parameters remain five attempts, a 10,000 ms deadline, delays of 2,000/5,000/10,000/20,000 ms, a 65,536-byte acknowledgement bound and `Idempotency-Key`. The named contract constant is the current policy source; generated migration SQL freezes its upgrade-time budget rather than importing runtime configuration.
- Preserve explicit loop deletion semantics rather than introducing a new 409 restriction. Missing runs stop with an informational log; persistence faults remain errors requiring recovery.
- Use one indexed projection query per result set, with the index explicitly selected because the sequence sort otherwise allows a scan of unrelated history.
- Tests bind port 0, including a briefly reserved/closed port for connection refusal. Store removal validates temporary parent/prefix and has three bounded retries with `retryDelay: 100` ms. The benchmark isolates native SQLite mappings in a worker that exits before parent cleanup.
