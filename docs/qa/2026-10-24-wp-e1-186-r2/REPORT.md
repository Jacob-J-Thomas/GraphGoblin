# 7. Decisions and parameters

512 retained rows and 1,048,576 estimated UTF-16 row-JSON bytes independently bound tiny-event and payload-heavy runs; cache framing/cursors add bounded overhead. The existing maximum 20 runs remains. A typical measured window spans about 40 cyclic passes. 128-event pages match server replay. 80 mounted rows avoid a fixed-height or new-dependency assumption. The pathological description preview remains 4,096 characters as in #259. Explicitly requested oversized payloads and server thread values retain their intrinsic size; they are not incidental persisted history. Selected snapshot queries retain zero inactive entries, replacing the old 32-thread browser cache.

An explicit Follow live action catches at most eight extra 128-event pages before either returning live or showing a finite retry reason. Last acknowledged SSE sequence is independent of displayed history, so browsing and reload cannot move it backwards. Displaced opaque boundaries are invalidated and reacquired by numeric seek. Server history remains complete. Latest lifecycle/exit/gate/finish evidence is read independently of the window; one indexed gate scan avoids per-ungated-event SQL round trips. Historical thread reads carry domain replay state across pages. These are engineering choices, not owner-approved limits.
