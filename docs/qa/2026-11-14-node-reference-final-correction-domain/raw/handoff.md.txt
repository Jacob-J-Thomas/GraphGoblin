## Correction

When the recognized JSONata lookup reads a known thread map, it still handles an unadorned string key as an ordinary keyed reference. For a computed key, it reports uncertainty for the outer identity and visits the evaluated key in the caller's focus. Only a direct existence probe about the key's own read marks that nested reference optional. A presence check wrapped around the outer lookup still evaluates its key as required. A string AST node carrying a predicate receives the same computed-key treatment because the installed evaluator runs the predicate. The existing parser, evaluator, binding analysis, source caches and focused traversal rules were reused. [Evaluator AST probe and output](lookup-ast-probe.jsonl).

The tests assert exact source bytes outside the replaced token, repaired-reference counts, preserved outer uncertainty and matching runtime values. They cover both a simple thread root and a row context with a local similarly named output, missing counters and gates including an outer presence probe, a filtered string key and an explicit inner presence probe. A variable-based computed key remains non-blocking and uncertain. Public domain isPublishable and validateLoop assertions cover the identified admission behavior.
