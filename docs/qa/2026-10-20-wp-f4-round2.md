The #244 CHANGELOG bullet's exact upgrade instruction is:

> **Upgrade:** on the old build, let every run inside an inference node finish or cancel it before upgrading: startup recovery automatically resumes `running` runs. After upgrading, never resume a failed run whose failure is on an inference node and whose log has no `harness.turn`; use Replay from the node, delete its loop, or reset the store.
