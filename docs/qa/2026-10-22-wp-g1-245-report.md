- **Fresh-entry guardrails are separate.** `countEntries` (`run-manager.ts:250-258`) counts attempt-1 starts only in the events supplied; the executor supplies the fork's own log at `:1501-1505`. `attemptFor` (`:239-247`) uses the fork's own unfinished starts. The fix preserves these semantics.
- **Gates inherit seed passes and update to absolute decision evidence.** The decision handler reads prior passes (`handlers/decision.ts:104`) and emits the resulting count (`:123-128`). Executor `run-manager.ts:1662-1666` and domain replay `replay.ts:69-74` install that absolute count. The nested replay test establishes passes 2 at its first event.
- **Iteration is copied from the pre-node source thread** (`run-manager.ts:909` and `:929`), and domain replay applies historical `iteration.incremented.to` (`replay.ts:76-78`). Fresh current-format runs remain at 1; synthetic historical iteration evidence is labeled as such.
- **Queued threads already work.** SQLite inserts the seed as initial thread and snapshot (`packages/infrastructure/src/sqlite/runs.ts:66-67`); `RunManager.getThread` returns that snapshot (`:1009-1016`). Public replay/thread regression and disposable API measurements verify this; no endpoint or query change.
