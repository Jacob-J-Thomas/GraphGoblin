# Inspector build and 12-case browser runner

The runner has two separate entry points. `build` accepts the root-bound final UIQA source and runs the installed pnpm 12.8.1 executable with structured argv `build` under project Node 22.23.4. `browser` also requires `BROWSER-ADMISSION.json` with the same source and the exact completed build-manifest SHA-256. The build command never starts Playwright. Each phase writes its original streams, timings, status and source snapshots to `i5-416-420-browser12-execution-01`.

The final UIQA binding carries head, tree, parents, linked index, both module files, 19 unchanged install inputs, the app/fixture/core pins and five allowed untracked overlays. The runner measures the materialized tracked bytes before and after each phase. The browser phase copies the hashed web output into a fresh owned directory and validates restoration of that copy and parity of the original dist after global teardown. The real test server runs the development-source API with the built web assets, through the existing Playwright global setup.

The four literal specs are the independent listener (5), independent strict geometry (2), author availability (4), and bounded-history (1). The single structured Playwright invocation uses one worker, zero retries, trace on, and each spec's existing deadlines. The runner records raw JSON and attachments, including the expected 12 strict geometry JSON samples, 12 corresponding PNGs and the matrix. Existing geometry assertions stay intact. A failed first run remains a failed run even when it produces all diagnostics.

The environment inherits selected Windows runtime values and private-provider overrides are absent. Build and browser receive separate owned temp directories. Browser settings explicitly bind MAIN and CONTROL to port 0, use the task data prefix, disable Ollama and leave LIVE, KEEP_STDIN and stale base/control URLs absent. The bound helper rejects protected ports 4747, 4748, 7443 and 11434. No browser install, existing profile reuse, process-tree termination, product-source edits or hidden retry is in the runner. Its direct command and native global teardown provide bounded process evidence. Any separate passive observer evidence remains qualified.

The browser admission template is unarmed. Build is separately root-authorized only on final `2231400e` after the exact UIQA FF. Attachments use the existing proposed and reviewed strict geometry helper bytes already present in UIQA.
