# Scenario design (written after reading helper/config/subprocess source, before reading author tests, caller test diffs, witness files or author README)

Mechanism read: per-run mkdtemp root provided by global setup; per-worker setupFile injects root;
reserveApiPort = validate range -> random offset -> mkdir(root/port) atomic claim + mkdir(owner uuid) marker
-> 127.0.0.1 bind probe -> keep claim; release = rmdir(marker) then rmdir(claim), memoised.
createApiProcessFixture holds the reservation for its lifetime; dispose kills+awaits children, then releases.

All native work restricted to 63800-63819, TEMP/TMP redirected to a QA-owned folder so the run root is observable.
