The *.template.js files retain the placeholders used to stamp fixture IDs for decision outputs, geometry and supplemental union checks. To repeat the checks, start a freshly built baseline gateway through gateway.mjs using the isolated worktree path. Open the local app in an isolated Edge Playwright CLI session, run setup.playwright.js and setup-outputs.playwright.js, then substitute only the newly returned fixture IDs into copies of the templates. Run the Wait probe while its dialog is open from setup. The other probes open their own fixtures. Run from a disposable evidence directory.

The initial setup artifact includes rejected auxiliary fixtures whose malformed definitions were corrected in setup-outputs.playwright.js. They were fixture corrections outside the findings.
