## F1 · P2 · Incomplete auth-check output can report the account as signed out

A started probe that loses stdout or stderr sets `outputFailed` and requests owned-tree termination. If termination is confirmed, its close code can be 1 or null. During `auth status`, the harness still infers a readiness state from the captured bytes. For a nonzero or null exit, the inferred state throws at lines 186–199 before the new unreadable-output guard at line 201. The auth handler then sets `authenticated: false` for an inferred auth failure. The public preflight endpoint returns that fact and advises signing in. ## F2 · P3 · A failure confined to the help probe loses its known cause

When `--version` succeeds, the capability check starts a separate `--max-turns 1 --help` process. If that start is refused and the runner establishes that its temporary check directory disappeared, `startFailure` creates the fixed missing-folder detail. The help catch catches every `HARNESS_TURN_FAILED` and substitutes “failed the --max-turns/--help check.” A started help process with unreadable output takes the same path once its output-loss guard fires. The catch therefore discards both new actionable causes. The public problems list receives the replacement text. A turn's prerequisite path also throws this first failure. If auth succeeds independently, the help cause is absent from the entire public response. [Cause creation](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/a04f6661a74a727e6c963d8648ea2998bb6dbe7b/packages/infrastructure/src/claude/harness.ts#L125-L135) · [Help wrapper](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/a04f6661a74a727e6c963d8648ea2998bb6dbe7b/packages/infrastructure/src/claude/harness.ts#L328-L350) · [Public problems](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/a04f6661a74a727e6c963d8648ea2998bb6dbe7b/packages/infrastructure/src/claude/harness.ts#L376-L389) · [Turn prerequisite](https://github.com/Jacob-J-Thomas/GraphGoblin/blob/a04f6661a74a727e6c963d8648ea2998bb6dbe7b/packages/infrastructure/src/claude/harness.ts#L442-L444)

The wrapper predates this PR. The lost check-folder and output-loss diagnostics are new behavior promised and implemented by this PR. The current folder test makes every command refuse, so the version probe fails before help runs. The unreadable-output test faults the auth command only. **Required correction.** Carry the specific process/start cause across the help wrapper while preserving ordinary versioned capability guidance for an actual option-check failure. Assert the fixed cause through public preflight and the turn prerequisite. These are source-established cases awaiting corrective execution.
