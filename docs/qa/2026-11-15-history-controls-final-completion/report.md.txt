The original brief's shorthand saying 36 px fine targets was inaccurate; its correction is retained in `root-brief-clarifications.md` without modifying the original brief.

UndoRedo's scoped `active:translate-none!` defeats the shared ghost-button active translation, while an enabled pressed border provides feedback. Shared Button styling and history actions, focusability, `aria-disabled`, labels, tooltips, `aria-keyshortcuts` and history payloads remain unchanged. Component tests verify semantics and compiled CSS; the retained native measurements establish actual geometry and hit behavior.

Connection ownership is tied to the mounted `EditorConnectionBanner` component. `EditorPage` renders it below the toolbar only after its loaded-frame early returns and while voice staging is not inert. The shell subscribes through `useSyncExternalStore`; unique Set claims, idempotent releases, and layout-effect acquisition/cleanup handle overlap, navigation, StrictMode and error-boundary replacement. Copying the listener set before notifying makes subscription changes during notification safe for the current callers. Late or remounted subscribers read the current snapshot. No claim is acquired for a render that never commits. A renderer failure releases the committed claim; retry reacquires it. The application is a browser client with the reviewed single shell; no new server request ownership or cross-user state is introduced.

The existing `useConnectionStatus` source, reconnect grace, offline/API-unreachable distinction and HTTP error classification are reused. API key, storage and shutdown notices stay with their existing shell owners. Auth, draft preservation, unsupported data, no-definition, loading and error paths remain intact. There are no new endpoints, external inputs, secrets, dependencies, persistence writes, schema changes, migrations or compatibility paths. History/store mutation and conditional save logic are not modified. I found no introduced security boundary, data-loss, lifecycle, cancellation or maintainability defect requiring a change.
