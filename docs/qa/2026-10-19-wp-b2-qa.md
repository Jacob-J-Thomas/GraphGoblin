## Decisions, limits and observations outside scope

- Failure injection used a regular file obstructing the artifact directory and real Windows file-share locks. This avoids ACL changes and directory deletion, and tests actual filesystem failures.
- The fallback race uses a real external writer and a filesystem notification to coordinate the final-file change. It models the winning identical writer; it is not a mock of `rename` or of the store.
- Exact start/resume request inspection is unavailable through the current e2e control endpoint. The public session API confirms session continuity; exact one-resume/prompt evidence comes from `artifact-failure.test.ts` in the passing engine run. No live-provider claim is made.
- Abrupt API process stop/restart was used for durable state reads. Power interruption, disk-full behaviour, malicious filesystem actors, SHA-256 collision resistance, prolonged endurance and browser rendering are outside this bounded QA.
- Native process-tree gate failures are sandbox artefacts under D-015, not WP-B2 defects. The unresolved upgrade/template timeout findings require orchestrator/reviewer disposition; they are not silently classified as sandbox artefacts.
- No before-fix checkout was executed: QA stayed on the assigned branch/revision. Historical reproduction claims in the implementation brief were not relabelled as newly reproduced baseline evidence.
- [cleanup.json](2026-10-19-wp-b2-qa/cleanup.json) records cleanup. All manually started API/MCP/e2e/lock-holder/native-script processes were stopped. All files in this QA's prefixed stores were removed. Empty directories remain because the brief prohibits deleting directories. Native-test descendant absence cannot be fully certified where sandbox process inspection/termination is denied; no gate fixture directories referenced by these logs remained at the final sweep. No unrelated processes were terminated.

- The orchestrator should reconcile the blanket failed-status omission wording with the documented authored-Failure return contract. Preserve the distinction between an operational node failure and a deliberate exit outcome when interpreting result presence.
- Generated `packages/contracts/coverage/` and `packages/engine/coverage/` directories remain for the orchestrator to retain or remove. QA did not delete them. Temporary probe scripts and raw gate logs were removed after extracting the compact evidence.
