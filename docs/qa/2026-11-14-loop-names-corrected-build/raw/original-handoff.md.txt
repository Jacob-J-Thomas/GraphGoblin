This is consistent with the sources of those packages being unchanged since 0d2 (the diff touches only `apps/web` and docs), but it is not proof of a from-scratch emit. If independent QA wants that proof, `tsc -b --force` on those packages needs a root grant. I did not delete any output.

I did not run web coverage, a full-repo check, or the unit, type and lint checks that already passed. The earlier 25 focused and 184 related passes are Opus's and were not repeated here.
