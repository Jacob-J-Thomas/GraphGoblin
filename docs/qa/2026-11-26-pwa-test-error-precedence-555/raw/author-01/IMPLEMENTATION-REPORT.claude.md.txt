## What changed (`apps/web/e2e/pwa.spec.ts` only, unstaged)
- **Helper `bodyThenCleanup(body, cleanup)`:**
  - The body runs first. If it fails, the cleanup runs once and the body's error is rethrown as the same object with the same stack.
  - If the cleanup also fails, its error is written to stderr and attached to the test as a text attachment (`guarded-update cleanup error`), cut to 2,000 characters. Neither needs a fixture, and any error while reporting it is swallowed so it can't replace the body's error.
  - If the body passes, a cleanup failure is still the test failure. If cleanup succeeds after a body failure, the outcome is unchanged.
- **Real test:** the title, the setup before the old `try`, every statement in the body, the timeouts and the transport are unchanged. The body is only indented two more spaces, so the raw diff is large; review it with a whitespace-insensitive diff. The two cleanup lines (close the dirty tab if still open, then `/worker/reset`) run in the same order, each at most once. I also added one type import (`TestInfo`).
- **Four controls**, each title containing `guarded-update-error-precedence` and none containing `unresolved`. None needs a browser, and every reset goes to an already-disposed request context, so nothing reaches the E2E server.

## When the cleanup diagnostic is visible
This is based on reading Playwright 1.63.0's source, not on a native run:
- After a timeout, Playwright disposes `request` (with no reason) before it closes the page's context, using the reason `Test timeout of 60000ms exceeded.`.
- The late body failure and the attachment arrive before Playwright reports the test as finished. On a failure, the list reporter prints both. It shows only the first 300 characters of the attachment, and stderr has the full text.
- Expected native result: `Test timeout…`, then `page.waitForEvent: Test timeout of 60000ms exceeded.`, plus the cleanup attachment and stderr line. Before, the reset error appeared instead of the wait error.
- If the body only finishes after Playwright has reported the test, the runner silently drops both the attachment and the late body error. The stderr line still prints, without a test name, unless the worker has already exited.
