## F3 · P2 · Publish a complete readiness record before the abort observer reads it

The new CLI fixture writes JSON directly to the final readiness path at `schema-cli.mjs` lines 11–21. Concurrently the host polls for the path, immediately parses its contents at line 48, and calls `controller.abort()` at line 51. The supported Node v22.23.4 string write opens the named file with flag `w`, writes its contents in a later filesystem operation and then closes it. The file already exists between the open and the write. A concurrent poll can therefore read an empty file and throw a JSON parse error before cancellation. The CLI’s abort mode holds an interval indefinitely. A failure on this path can also leave the helper running if it has reached that wait. Both processes can follow their normal code paths for this to occur.
