## Reproduce

Copy the runner to an external disposable directory. From project-scoped Node 22.23.4, point it at the dependency-installed source checkout at the exact head above.

```powershell
$source = '<candidate worktree>'
$runner = '<external>/verify-273-backend.mjs'
$loader = ([uri](Get-Item -LiteralPath "$source/apps/api/node_modules/tsx/dist/loader.mjs").FullName).AbsoluteUri
node --conditions=development --import $loader $runner $source
```
