## Observed groups

Five scoped first-attempt groups passed: the 360 px guard, offline recovery, full-transport abort, PUT-only flash, and controlled HTTP 500 handling. These are bounded scenarios, not a complete QA matrix. The run records, observed summaries, actions, browser snapshots, and raw frame JSON are retained under [runs/](evidence/source/runs/); all 10 run records and action files and all 37 raw frame files are included. Nine runs have `observed.json`; `h-d1-first` has no such summary or per-run `history.playwright.js`, and neither is reconstructed. The shared root driver and the distinct `h-d1-correction1` driver are retained; byte-identical per-run script copies are omitted and mapped to their exact retained paths and hashes in `omissions.json`. Per-run observations, actions, and available browser snapshots are retained for all 10 runs. The `h-d1-first` folder has no per-run `history.playwright.js`; this packet does not reconstruct one.

The D1 persistence/history case remains incomplete. The two fixture-correction batches were exhausted. Correction 1 fixed ready-state paint/readback quoting; correction 2 accounted for the three canonical Script defaults and added GET/PUT/device observations. That run then stopped on a different driver defect: `recordAdd` dereferenced missing `.draft.definition` after the post-Publish GET. No third correction was applied. The full GET response body was not serialized. The conclusion that the API followed its current-or-draft contract is an inference from the observed HTTP 200s, executed branch, and source contract—not a captured GET-body assertion. See [fixture-correction ledger](evidence/source/fixture-corrections.json), [first D1 correction](evidence/source/runs/h-d1-correction1/run.json), and [second D1 correction](evidence/source/runs/h-d1-correction2/run.json).

In the bounded D1 controls, the actual Checking-to-Ready indicator changed from 87.359 to 123.844 CSS px; held Publish and post-Publish history boxes remained fixed; Undo and Redo led the toolbar in forward and reverse keyboard traversal; a disabled top-row Undo click preserved focus with zero writes; and a one-frame, 1 px positive control was detected. These observations do not establish physical touch-hold behavior or actual browser text zoom.

Ownership-transfer/error evidence is partial. The D1 and R512 runs observed a 404 GET, but releasing the response after going offline left the UI Loading with the shell banner. The final error view was not reached, so the ownership 404 error route is unwitnessed. In the HTTP 500 scenario, controlled POST validation and PUT draft requests returned 500 without a connection banner, and a subsequent edit stored the graph. The raw-frame filename `frames-open.json` was reused; the later healthy capture overwrote the earlier validation-failure frame. Request/action/status records remain available, but that overwritten frame cannot be recovered from this packet.

Each of the 10 runs completed cleanup; the final cleanup record hashes to `28ca827e429fad1004ed749f314dd96c0b51905b7571b99d69bda6b15dec2450`. The cleanup record reports no remaining owned browser or gateway processes. See [cleanup record](evidence/source/cleanup-final.json).

## Limits and selection

This is partial evidence only. It does not claim the complete history matrix, successful D1 completion, ownership 404 error handling, current-main integration, final native acceptance, formal review, current-target CI, or owner acceptance. Screenreader behavior, multiple browser engines, a complete touch sequence, physical touch hold, and actual browser text zoom were not covered. A separately admitted higher-tier Astra offline recovery is outside this packet and is not represented as completed here.

The source inventory contained 262 files / 14,744,808 bytes. This packet contains 214 exact raw copies / 7,629,271 bytes, including all 37 raw frames; the largest copied file is 869,116 bytes. It omits the isolated Turbo cache (30 files / 6,712,569 bytes) and 18 per-run scripts that are byte-identical to retained root copies (10 gateway copies and 8 history-driver copies; 402,968 bytes total). The duplicate paths, hashes, and retained equivalents are enumerated in [omissions.json](omissions.json). All other inventoried safe source files are retained. Original source files remain untouched.

`SHA256SUMS.txt` covers the packet files other than itself. `.gitattributes` marks copied evidence as binary so Git does not normalize line endings.
