## Change and focused evidence

When `-NodePath` is omitted and `node.exe` is not on `PATH`, the parameter default now uses `Select-Object -ExpandProperty Source`. An empty discovery result passes to the existing `Get-InstallerNode` guard, which emits its missing-Node guidance, instead of dereferencing `.Source` under caller `Set-StrictMode -Version Latest`. Explicit `-NodePath` values continue through the existing validation path.

The acceptance test now omits `NodePath` in both cases. With only the Windows system directories on the child `PATH`, it asserts exit code 1, the missing-Node guidance mentioning Node 22 and `-NodePath`, no `.Source`/`PropertyNotFoundStrict` error, an unchanged installed-file snapshot, and an empty store. The regex does not independently require the literal `22.22.2`; existing installer acceptance cases cover version-floor refusals. A positive default-discovery control exposes the known Node directory in the child `PATH`, then checks successful installation, the discovered executable path, and the valid PWA's existing port.

- [Pre-fix regression output](focused-prefixed.log) failed because the original default raised `PropertyNotFoundStrict` on `.Source`; [exit receipt](focused-prefixed-exit.json).
- [First post-fix attempt](focused-postfix.log) reached the positive control but was refused because its fixture used a different port from the app ID in the valid PWA shortcut. This was a test-fixture mismatch, not a product failure; [exit receipt](focused-postfix-exit.json).
- After the positive fixture reused the PWA's valid port, the [focused PS5.1 group](focused-final.log) passed 1/1 with exit 0 under Node `v22.23.4`; [command and exit receipt](focused-final-exit.json). It exercises the real Windows PowerShell 5.1 installer path and the valid default-discovery control.

The focused test ran before the documented formatting-only MJS edit. No test was rerun after formatting. Scoped ESLint passed; the initial Prettier check failed, then the MJS file was formatted and the final scoped Prettier check passed. Both initial and final `git diff --check` passed.
